# Security Policy

## Overview

Engineering Decisions is a curated collection of reproducible cloud-native laboratories intended for educational purposes.

The examples, infrastructure definitions, and sample applications are designed to demonstrate engineering concepts and should be reviewed and adapted before being used in production environments.

---

## Security Scope

This repository may include:

- Kubernetes manifests
- Infrastructure as Code
- Container configurations
- Sample application code
- Deployment scripts

While every effort is made to follow engineering best practices, these examples are provided as educational references rather than production-ready solutions.

---

## Reporting Security Concerns

At this time, this repository does not accept public issue reports or external contributions.

As the project evolves, a dedicated process for reporting security concerns may be introduced and documented in this file.

---

## Responsible Use

Readers are encouraged to:

- Review every configuration before using it in production.
- Validate security settings according to their own organizational requirements.
- Treat each laboratory as a learning resource rather than a drop-in production implementation.
